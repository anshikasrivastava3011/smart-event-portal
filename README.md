# Smart Event Management Portal

A Smart Event Management Portal created as a DevOps capstone project.

The application allows users to:

- Browse upcoming events
- Book event tickets
- View booking history
- Add, update and delete events through backend APIs

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Docker
- Kubernetes
- Jenkins
- GitHub
